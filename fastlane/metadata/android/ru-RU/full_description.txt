<h2>Возможности</h2>
<ul>
  <li>Организация закладок по нескольким спискам</li>
  <li>Открытие сохранённых закладок в системном браузере</li>
  <li>Приём ссылок, отправленных из других приложений</li>
  <li>Выбор списка назначения перед сохранением ссылки</li>
</ul>

<h2>Как это работает</h2>
<ul>
  <li>Nori помогает сохранять интересные ссылки из любых приложений и упорядочивать их по спискам.</li>
  <li>Когда вы будете готовы к чтению, Nori откроет ссылку в вашем системном браузере для наилучшего удобства.</li>
</ul>
