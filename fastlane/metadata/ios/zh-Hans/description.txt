Nori 是一款书签管理与稍后阅读应用，为你保存的链接安个家。收集文章、视频、工具和灵感，再通过可视化预览、列表、标签和笔记轻松找回。

从任意应用保存链接
在浏览器或其他应用中将链接分享到 Nori，并选择要存入的列表。整理一份稍后阅读清单，或为项目收集资料。

带上下文的可视化书签
每个书签都会显示为带封面图或网页截图的卡片。添加标签和个人笔记，记住当初保存的原因；也可以切换为紧凑列表。

几秒内找到任何链接
搜索书签，并按列表或标签筛选。通过历史记录快速回到最近打开的链接。

批量整理
将书签分类到自定义列表。一次选择多个书签，即可一起移动、隐藏、分享或删除。

导入与导出
通过 HTML 文件或纯文本网址列表，从浏览器或其他书签管理工具导入书签。随时导出为 HTML 或纯文本。

打造你的风格
可选浅色、深色或纯黑 AMOLED 主题。选择强调色或自定义颜色，调整文字大小，并选择适合你的书签布局。

随心阅读
在 Nori 内或默认浏览器中打开已保存的链接。

手机、电脑、浏览器全覆盖
Nori 支持 Android、iPhone、iPad、Windows、macOS 和 Linux，并提供 Chrome 和 Firefox 扩展。书签保存在你的设备上；登录后，可选的付费方案 Nori Sync 会在所有设备间同步列表和书签。
